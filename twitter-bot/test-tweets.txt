# --- Dates and "by" ---
"by" + year: should ask which reading | | Bitcoin hits 150k by 2027
"by the end of": should NOT ask about the date | | Bitcoin hits 150k by the end of 2027
"by" + weekday: should ask | | Apple announces a foldable iPhone by Friday
relative date: should work out the exact date and show it | | Taylor Swift announces a new tour next Tuesday
abbreviation EOY: should treat as end of year | | BTC 🚀 200k EOY
"within": window, no "by" question | | OpenAI releases GPT-6 within 6 months
"on" a date: single moment, not a window | | The S&P 500 closes above 7000 on Dec 31, 2026
no deadline: should ask for one | | Humans will land on Mars eventually

# --- Vague words and thresholds ---
vague word: should ask what "crash" means | | The housing market is going to crash soon
numeric "around": should push back with yes/no options | | Gold will be around $3000 by summer
"no one in the car": should ask empty car vs no driver | elonmusk | Tesla robotaxis with no one in the car in Austin by the end of 2026

# --- Market type ---
open-ended, multiple outcomes: should push back to yes/no | | Who wins the Super Bowl this season?
two claims joined by "and": one combined market, don't ask which | | BTC to 150k and ETH flips it by the end of 2027
conditional: should ask how to handle the "if" | | If the Fed cuts in December, stocks rip in Q1

# --- Not predictions ---
opinion: should decline | | AI is overhyped
sarcasm: should decline (or ask) | | Sure, and I'm sure GPT-6 ships tomorrow 🙄
already happened: should decline | | Trump wins the 2024 election

# --- Sources and the tweet's author ---
company claim: source must not be Elon's or Tesla's X posts | elonmusk | Tesla will have unsupervised FSD in every US city by the end of 2027 | hold up format; public rides; cities over 100k
only the author can verify: should ask for a verifiable resolution source | | I'll run a marathon under 4 hours by the end of next year
negative prediction: keep the framing, don't flip it | | The Lakers won't make the playoffs this season

# --- Requester's note ---
note conflicts with the tweet: should ask which prediction | someguy | Bitcoin will crash below 50k by the end of 2026 | actually I think it hits 200k
note sets the wording: should use the requester's question | someguy | Nvidia will be the first $10T company by the end of 2027 | call it "Will Nvidia hit $10T first?"
